## Featured project

### [KaamKhata — workforce register for labour contractors](https://github.com/ash051994/kaamkhata)

An offline-first Android app that replaces the paper register a labour contractor uses to manage 50–100 factory workers in MIDC industrial areas.

<table>
<tr>
<td width="55%" valign="top">

- **Payroll engine** with PF, ESIC, Maharashtra profession tax, overtime, bonus and advance recovery — pure, unit-tested functions
- **Voice data entry** in English, Hindi and Marathi: speak a worker's details and the form fills itself
- **KYC checks**: Aadhaar Verhoeff checksum, PAN, IFSC, UAN validation; document photos with verify/reject
- **Reports** as PDF and Excel — payslips, wage and attendance registers, PF/ESIC summaries — via a dependency-free PDF writer that renders Devanagari
- **No backend**: IndexedDB storage, backup/restore, PIN lock; wrapped for Android with Capacitor
- **CI/CD**: GitHub Actions runs unit + Playwright end-to-end tests, builds the APK/AAB and deploys a live web demo

**Stack:** JavaScript (ES modules), IndexedDB, Web Speech API, Canvas, Capacitor, Playwright, GitHub Actions
